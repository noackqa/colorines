# Colorines 🎨

App de colorear para tablet (PWA) pensada para peques de ~4 años: colorear con el dedo o rellenando zonas con un toque, modo libre con purpurina y pegatinas, y voz en español, inglés y alemán.

- Sin servidor ni dependencias: HTML + Canvas + JS.
- Funciona sin internet una vez instalada (service worker).
- Voces generadas con ElevenLabs (`audio/`), con la voz del sistema como respaldo.

## Probar en local

```bash
python -m http.server 5173
```

## Instalar en Android

Abrir la URL de GitHub Pages en Chrome → menú ⋮ → «Añadir a pantalla de inicio».
